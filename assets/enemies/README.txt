敵キャラのイラストを差し替える方法
-----------------------------------
正方形のPNG画像(背景透過推奨、128x128以上を推奨)を、js/data.js内の
その敵の id と全く同じファイル名にして、このフォルダに置いてください。

  guardSoldier.png       (衛兵)
  houndScout.png         (追跡犬)
  cursedArmor.png        (呪われた鎧)
  wanderingMaid.png      (彷徨う侍女の霊)
  eliteKnight.png        (エリート騎士)
  bossKnightCaptain.png  (騎士団長ヴァルガ)

ゲームは起動時にこのフォルダを自動でチェックします。該当するファイルが
あれば、その敵の絵文字の代わりに画像が使われます(硬さを表す色付きリング
はそのまま円形の画像の周りに表示されます)。ファイルが無い場合は今まで
通り絵文字表示になるだけで、エラーにはなりません。コードの変更は不要です。

新しい敵キャラを追加する場合(例:リスナーから提供されたキャラクターなど)
1. js/data.js の ENEMY_TYPES に新しい項目を追加してください。
   必要な項目: 一意のid、name(表示名)、icon(絵文字)、hp、speed、damage、
   radius、color、tier(硬さ 1〜3。ただしエリート敵やボス敵にする場合は
   tierの代わりに elite:true または boss:true を指定)。
   経験値(xp)は hp と damage から自動計算されるため、強いキャラほど
   自動的に多くの経験値になります。手動でのバランス調整は不要です。
2. js/data.js の WAVES のいずれかの項目に、そのidを追加して実際に
   出現するようにしてください。
3. 必要であれば、このフォルダに <id>.png を置いてイラストを反映させて
   ください。
